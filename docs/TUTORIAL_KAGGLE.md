# Kaggle tutorial

The maintained tutorial is [KAGGLE_WORKFLOW_FA.md](KAGGLE_WORKFLOW_FA.md).
It includes exact notebook order, configuration variables, input/output
handoffs, real versus fixture data, and the remaining model/training gaps.

Start with the root `english-streaming-asr.ipynb`. The old tutorial's adaptive
routing commands, waveform decoder factories and mandatory WhisperRT sequence
no longer apply. Do not run them against the continuous SURT pipeline.
