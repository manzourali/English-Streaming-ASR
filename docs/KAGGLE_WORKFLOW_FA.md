## نقش نوت‌بوک‌های موجود

چهار نوت‌بوک باقی‌مانده ابزار تشخیصی scaffold انگلیسی/native هستند؛ مسیر اجباری فارسی پس از smoke محسوب نمی‌شوند. فایل اصلی دادهٔ LibriSpeech و مخلوط‌ها را می‌سازد؛ 12 به export سازگار نیاز دارد، 13 فعلاً بدون backend فقط اعتبارسنجی می‌کند و 14 رکوردهای واقعی را مقایسه می‌کند. خروجی این فایل‌ها، به‌تنهایی مدل تطبیق‌یافتهٔ فارسی نیست.

داده‌های صوتی و checkpoint در output/input مجاز نگه داشته شوند؛ در Git قواعد داده، script/config، prompt و گزارش کوچک همراه hashها ثبت شود. برای session جدید، خروجی ذخیره‌شده را متصل و مسیر دقیق آن را در config وارد کنید. باقی‌ماندن فایل‌ها به معنی باقی‌ماندن RAM، فرایند GPU یا قابل‌انتقال‌بودن venv نیست.
