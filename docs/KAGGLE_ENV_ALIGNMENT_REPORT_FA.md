# گزارش تطبیق پروژه با محیط کگل

تاریخ: ۲۰۲۶-۱۱-۱۲

کد، نصب نوت‌بوک‌ها و راهنماهای فعال با توجه به `kaggle_env_info.md` اصلاح شدند. نتیجهٔ این کار کاهش احتمال تعویض ناخواستهٔ پشتهٔ موجود، تشخیص زودتر خطاهای محیط و رفع اشکال انتخاب دستگاه است. حداکثر سرعت، دقت مدل و بی‌خطابودن اجرا روی کگل بدون آزمون واقعی قابل تأیید نیست.

## مبنا و یافته‌ها

گزارش شما Python 3.13.15، NumPy 2.1.3، Torch/torchaudio 2.11.0+cu128 و دو Tesla T4 با 15360 MiB حافظه برای هر کارت دارد. این اطلاعات به `configs/kaggle_environment.json` منتقل شدند تا ابزار بررسی محیط بتواند اختلاف نسخه‌ها را گزارش کند. فایل اصلی شما تغییر نکرد.

برچسب Colab در کنار مسیر کگل ناسازگار بود؛ تشخیص جدید نشانه‌های محیط را جدا ثبت می‌کند. Python 3.10 در Conda با تصویر گزارش‌شده همسان نبود. همچنین مسیر قدیمی Icefall به Python 3.12 و wheelهای نسخه‌حساس خودش وابسته است؛ یکسان‌کردن اجباری آن با کرنل اصلی تصمیم مناسبی نبود.

## اعتبارسنجی انجام‌شده

محیط آزمون محلی macOS arm64 با Python 3.12.0 و NumPy 1.26.1 بود؛ این محیط همان کگل گزارش‌شده نیست. فایل `outputs/audit/local_environment_2026-11-12.json` مشخصات اجرای محلی را ثبت می‌کند.

- `python3 -m pytest -q -rs`: **82 passed, 6 skipped**؛
- `python3 scripts/validate_notebooks.py`: **5/5 valid**؛ کد سلول‌ها کامپایل شد و خود سلول‌ها اجرا نشدند؛
- `python3 -m compileall -q src scripts`: موفق؛
- `git diff --check`: موفق؛
- بررسی محیط با پروفایل core و ذخیرهٔ JSON: موفق.

شش مورد skip به نبود Torch، Lhotse، وابستگی‌های نرمال‌سازی فارسی و SentencePiece، و تنظیم‌نشدن integration واقعی مدل مربوط بودند. دو GPU و BF16 با شبیه‌سازی رابط دستگاه تست شدند؛ تست روی دو T4 واقعی انجام نشده است. اجرای pip در تست setup شبیه‌سازی شد تا محیط محلی تغییر نکند.

## مواردی که هنوز نیازمند اجرای واقعی‌اند

1. نصب extraها و اجرای نوت‌بوک در تصویر Python 3.13.15/NumPy 2.1.3 کگل؛ سازگاری این ترکیب از روی گزارش به‌تنهایی اثبات نمی‌شود.
2. import و smoke واقعی k2/kaldifeat در محیط جداگانهٔ runbook؛ نسخه‌های آن recipe خودسرانه ارتقا داده نشدند.
3. اجرای مدل/وزن واقعی، انطباق feature/export، اندازه‌گیری VRAM، سرعت، loss و دقت؛ backend/export کامل مدل همچنان پیش‌نیاز مستقل است.
4. آموزش چند GPU؛ موجودبودن دو کارت به معنی پشتیبانی backend از DDP یا جمع‌شدن حافظه‌ها نیست.

برای اجرای بعدی، سورس اصلاح‌شده باید در مخزنی که نوت‌بوک clone می‌کند در دسترس باشد. سپس جلسهٔ تازهٔ کگل را شروع کنید و سلول setup را اجرا کنید؛ فایل‌های environment، constraint، pip freeze و لاگ خطاها را با خروجی‌ها ذخیره کنید. در این کار branch، commit، push یا تغییر remote انجام نشده است.
