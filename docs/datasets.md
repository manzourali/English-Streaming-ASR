# Datasets

Planned roles are LibriSpeech (development/training), synthetic overlap (controlled generation), LibriSpeechMix (controlled multi-talker evaluation), LibriCSS (continuous overlap), and optional AMI/CHiME-6 generalization. In Phase 0 these are **planned**, not downloaded, validated, or processed. Backend interfaces support local files, Kaggle inputs, and a future Hugging Face adapter.
